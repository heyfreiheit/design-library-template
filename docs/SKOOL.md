# Deine eigene Design Library – Ressourcen zum Video

Sammle gute Websites nicht nur als Links: Bewahre die Gestaltungsidee, das Vokabular, Bildrezepte und passende Briefings direkt daneben auf.

**Vorlage:** https://github.com/heyfreiheit/design-library-template

**Loslegen:** Deploy-Button in der README nutzen oder eine eigene GitHub-Kopie erstellen und mit Vercel verbinden. Die README führt durch die einmalige Einrichtung mit Neon-Datenbank, privatem Bildspeicher und eigenem Login. Keine VPS-Einrichtung nötig.

**Mit KI einrichten:** `docs/EINRICHTUNGSPROMPT.md` in Codex oder Claude Code verwenden. Der Assistent hilft beim vorhandenen Projekt und den Cloud-Verbindungen.

**Startinhalt:** 34 ausgewählte Designprofile mit Einordnung und Original-Link. Unter Einstellungen kannst du über deinen Browserless-Zugang die Screenshots selbst erstellen lassen. Die ursprünglichen Chase-Demo-Referenzen sind nicht enthalten.

**Danach:** API-Schlüssel von OpenAI oder Anthropic hinterlegen, Modell wählen, erste Referenz hinzufügen und ein Briefing kopieren. API-Nutzung und Browseraufnahmen können Kosten verursachen. Vercel Hobby ist für persönliche, nicht kommerzielle Projekte vorgesehen.

**Datenspeicherung:** Designs und Schlüssel liegen dauerhaft in deiner eigenen Cloud. Ein anderes Gerät meldet sich an derselben Library an. Lege regelmäßig Backups an.
